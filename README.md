# Stashed

**Never lose anything you saved again.**

Stashed is a browser extension that replaces the bookmark manager with a personal memory system for the web. Save anything in one click, find it again in seconds.

- 📌 **Save anything instantly** — `Alt+S` on any page
- 🔍 **Find it again fast** — fuzzy search across titles, tags, domains, notes
- 📁 **Optional collections** — folders if you want them, none if you don't
- 🏷️ **Auto-tagging** — pages get tagged for you, no AI involved
- 💾 **100% local** — no account, no server, no tracking. [Read the privacy policy →](./PRIVACY.md)

## Install

### Firefox (recommended for early access)

1. Download [`stashed-1.0.0-firefox.zip`](https://github.com/toomanybits/stashed-downloads/releases/latest) from the latest release
2. Unzip
3. Open Firefox 126 or newer, visit `about:debugging#/runtime/this-firefox`
4. Click **Load Temporary Add-on…**, select the unzipped `manifest.json`
5. Pin to toolbar

> Firefox temporary add-ons disappear when you close Firefox. We're submitting to the official Firefox Add-ons store right now — once approved (1–3 days), you'll be able to install permanently with one click. [Watch this repo](https://github.com/toomanybits/stashed-downloads/subscription) for the update.

### Chrome / Edge / Brave / Arc

1. Download [`stashed-1.0.0-chrome.zip`](https://github.com/toomanybits/stashed-downloads/releases/latest) from the latest release
2. Unzip
3. Open `chrome://extensions/` (or `edge://extensions/`, etc.)
4. Turn on **Developer mode** (top right)
5. Click **Load unpacked**, select the unzipped folder
6. Pin to toolbar

> We're submitting to the **Microsoft Edge Add-ons** store (free, 1–7 day review) and the **Chrome Web Store** is coming soon. Until then, sideload via the steps above.

## Privacy

Stashed is local-first. Everything you save is stored in your browser. We have no server, no account system, no telemetry, no analytics. Read the [full privacy policy](./PRIVACY.md).
